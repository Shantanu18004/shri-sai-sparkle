# Shri Sai Jewellers – Premium Jewellery E-Commerce Platform

A modern full-stack jewellery e-commerce website built with React, TypeScript, Supabase, and Lovable.

## Overview

Shri Sai Jewellers is a jewellery e-commerce website that I built as part of my journey into full-stack development.

My academic background is in Artificial Intelligence and Machine Learning (AI/ML), and this project helped me understand how modern web applications are built using frontend technologies, databases, authentication systems, and cloud backends.

The website includes a customer-facing storefront and an admin dashboard for managing products, categories, inquiries, and gold rates.

## Project Overview

Shri Sai Jewellers is a premium jewellery e-commerce platform designed to provide customers with a seamless online shopping experience while giving administrators complete control over products, categories, orders, inquiries, and live gold pricing.

The platform includes a customer-facing storefront and a secure role-based admin dashboard.

## Live Gold Rate System

The platform includes a live gold pricing module.

Supported Purities:

- 24K Gold
- 22K Gold
- 18K Gold

Features:

- Automatic gold rate updates
- Realtime synchronization
- Dynamic product price calculation

Price Formula:

Final Price =
(Gold Weight × Current Gold Rate)
+ Making Charges
+ Stone Charges
+ GST
